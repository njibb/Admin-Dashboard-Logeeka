# Admin Dashboard Logeeka

Proyek ini adalah sistem dashboard admin untuk pengelolaan konten (Berita, Portofolio, FAQ) website PT Logeeka Grup Indonesia.

## 🛠️ Environment & Prerequisites

Sebelum melakukan instalasi dan menjalankan proyek ini, pastikan menggunakan versi environment berikut untuk menghindari *error/conflict*:

- **Node.js**: v24.13.1 
- **Next.js**: v16.1.6 

*(Catatan: Sesuaikan angka "x.x" di atas dengan versi asli di laptopmu ya cuy. Cek Node.js pakai perintah `node -v` di terminal, dan cek versi Next.js di dalam file `package.json`)*
